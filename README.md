## ✨ About

PathFinder is an interactive application that demonstrates how different AI search algorithms solve mazes. Visualize their search processes, compare their performance, and explore basic machine learning concepts through regression and classification.

## 🚀 Features

- 🧩 **Maze Creation** – Generate and customize mazes.
- 🔍 **Search Visualization** – Watch algorithms explore the maze.
- ⚡ **Algorithm Race** – Compare multiple algorithms side by side.
- 📊 **Performance Benchmarking** – Compare execution time, explored cells, and path length.
- 🧠 **ML Experiments** – Explore basic regression and classification.
- 📈 **Result Analysis** – Visualize and compare experimental results.
