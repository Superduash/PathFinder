About PathFinder

Algorithms

Heuristics

Metrics

  • Nodes expanded: nodes removed from the frontier and expanded.
  • Path length / cost: moves, and summed entry costs (diagonals ×√2).
  • Peak frontier: max distinct frontier cells.
  • Execution time: benchmark only, perf_counter_ns around run().
  • Optimality = C* / C, where C* comes from an independent Dijkstra (1.0 is optimal; undefined if unsolvable).
  • Accuracy appears only in the ML Lab.

Problem formulation and PEAS

State: a free cell. Actions: 4 or 8 moves, no corner cutting. Cost: entry cost of the cell (floor 1, sand 3, water 5). Goal test: cell = goal.

Performance: cost, expansions. Environment: static grid. Actuators: moves. Sensors: full map.

Syllabus mapping

Uninformed search (BFS, DFS, UCS), informed search (Greedy, A*), heuristics and admissibility, evaluation of search, basic ML (regression, classification).

Not implemented

IDA*, bidirectional search, other maze generators, neural networks, multi-agent search.

Keyboard shortcuts

Space start/pause · S step · R reset · 1–5 toggle algorithms (Visualizer, not while typing).
